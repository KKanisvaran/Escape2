# CODE POSTHUME — Dialogues cinématique v11

## Direction

Le développeur n'est jamais présenté comme suspect.  
Il est simplement **un homme ordinaire qui, soudain, a très peur**.

La cinématique ne donne ni son nom, ni son projet, ni la raison de sa fuite.  
Le joueur apprend son identité seulement après être entré dans le terminal.

La fuite conserve volontairement les répliques d'origine : elles ont le bon rythme et surtout elles ne donnent aucune réponse.

# ENTRÉE DANS LE JEU

Le terminal ne révèle plus le projet avant que le joueur enquête.

Il affiche seulement :

`Support endommagé monté en lecture contrôlée.`

`Volume chiffré détecté : /mnt/data_cache`

`Verrouillage définitif à la fin du compte à rebours.`

`Aucune identité chargée dans le dossier de session.`

`Commencez par examiner le répertoire courant : ls`

Le joueur peut ensuite découvrir **LISEZMOI.txt**, puis seulement à ce moment apprendre l'identité du développeur.

La progression devient :

**accident → ordinateur → terminal → identité → vie du développeur → intrusions → verrou → fragments → projet → message posthume.**
