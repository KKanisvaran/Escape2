# Dialogues — Cinématique (v8)

> Direction suivie : les images racontent l'action, les dialogues racontent les personnages. Phrases courtes, sous-entendus, silences. Personne n'explique ce que le spectateur voit déjà.
>
> **Personnages :**
> - **LE DÉV** — le développeur, personnage principal (jamais criminel, jamais suspect — juste un geek discret)
> - **POLICIER 1 / POLICIER 2** — les flics sur la scène de l'accident (Acte IV uniquement, anonymes, ils ne savent rien de lui — pas besoin de noms, ça sert leur côté interchangeable/radio)
> - **DUBOIS / ROUX / LEFEVRE** — l'équipe forensique (Acte V, récurrents, sarcasme de collègues de 12h/jour)
> - **LA RESPONSABLE** — la commanditaire Division 7 (calme, économe en mots, jamais déstabilisée)
> - **L'EXPERT** — le hacker recruté (une réplique d'avance sur tout le monde, négocie tout, perd son sourire une seule fois — au moment clé)
>
> `(...)` = silence / beat, pas de texte à l'écran — juste une pause dans le montage.
>
> *Ancienne correspondance (au cas où tu veux comparer avec le HTML actuel) : a→LE DÉV, b→POLICIER 1 (Acte IV) / DUBOIS (Acte V), c→POLICIER 2 (Acte IV) / ROUX (Acte V), e→LEFEVRE, d→LA RESPONSABLE, f→L'EXPERT.*
